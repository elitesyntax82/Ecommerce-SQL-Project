# 🛒 Ecommerce SQL Data Analysis Project

## 📌 Project Overview

This project is an E-commerce database created using MySQL to analyze customer purchases, product sales, category performance, and monthly revenue.

The project demonstrates practical SQL skills including database creation, table relationships, JOINs, aggregate functions, subqueries, CASE statements, CTEs, and window functions.

---

## 🛠️ Tools & Technologies

- MySQL
- SQL
- MySQL Workbench
- GitHub

---

## 🗄️ Database Tables

The database contains 5 main tables:

1. **Categories** – Stores product categories
2. **Customers** – Stores customer information
3. **Products** – Stores product details and prices
4. **Orders** – Stores customer order information
5. **OrderDetails** – Stores products and quantities for each order
